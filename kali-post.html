Install Kali Linux

Kali Linux is a popular OS for ethical hacking and cybersecurity. In this post, I'll show you how I installed it step by step, what tools I used, and what I learned from it.

🛠️ What You’ll Need

  • Kali ISO from the official site
  • VirtualBox, VMware, Hyper-V Manager
  • Some basic terminal knowledge

💡 Installation Steps

  1. Download the Kali Linux ISO
  2. Create a new virtual machine in for example Hyper-V Manager
  3. Mount the ISO and boot into the installer
  4. Follow the setup (language, keyboard, disk) and mostly agree everything
  5. Wait for it to finish and boot in 🎉

🐞 Troubleshooting

If you run into issues (like network errors or install hangs), check your VM settings — especially networking and memory. Also make sure you install it properly and install the correct one, otherwise it's going to get problematic.

🔧 After Setup

Once installed, run sudo apt update && sudo apt upgrade to get the latest updates. Then install your tools or wordlists. The tools are mostly not so necessary since Kali Linux has a LOT of them preinstalled.

📚 What I Learned

  • How to install a Linux distro using a virtual machine from scratch.
  • The difference between virtualization tools like Hyper-V, VirtualBox, and VMware.
  • That Kali Linux already includes most of the tools, so you don’t always need to install extra stuff.
  • How to troubleshoot basic VM issues like networking, ISO errors, or slow installs.
  • The importance of keeping your system updated with sudo apt update && sudo apt upgrade.

✅ Conclusion

Installing Kali Linux was my first real step into the ethical hacking world. It showed me how powerful a properly set-up system can be, and how important it is to understand the basics before diving deeper. Now that it's ready, I can finally start learning and testing tools in a safe environment. Let's go! 🚀
