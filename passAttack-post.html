🔐 Password Attack with Hashcat

One of the most intense but interesting things I tried was cracking passwords using Hashcat. In this post, I’ll walk you through my process of setting it up, experimenting with hashes, and finally managing to crack a password. This one took time, patience, and a bunch of trial and error! 🧠💻

🛠️ What You’ll Need

  • A Linux-based system (Kali Linux preferred)
  • Hashcat installed (sudo apt install hashcat)
  • Access to /etc/passwd and /etc/shadow
  • Rockyou wordlist: sudo apt install wordlists && gunzip /usr/share/wordlists/rockyou.txt.gz
  • Optional: Create your own wordlist
  • SSH access if working remotely: sudo apt install ssh

💡 Step-by-Step Process

  1. Update your system and install Hashcat: sudo apt update && sudo apt install hashcat
  2. Check Hashcat version: hashcat -I
  3. Extract hashes from /etc/shadow and /etc/passwd
  4. Combine them into a new file like hash.txt
  5. Try cracking with: hashcat -m 1800 -a 0 hash.txt /usr/share/wordlists/rockyou.txt --force -O
  6. If no success, create a user: sudo useradd hashuser & then sudo passwd hashuser
  7. Get the hash: sudo cat /etc/shadow | grep 'hashuser' | cut -d ':' -f2
  8. If the hash format starts with y instead of 6, it means the encryption method is wrong. Switch to SHA512 by updating your system password settings.
  9. Make a new user again. Check for the $6$ format.
  10. Set up SSH if needed: sudo apt install ssh → ssh username@ip
  11. Create a file on the target VM and paste the correct hash inside hash.txt
  12. If rockyou.txt doesn’t work, create customlist.txt with known passwords including the correct one
  13. Crack again: hashcat -m 1800 -a 0 hash.txt customlist.txt --force -O --potfile-disable

🐞 Troubleshooting

  • Hashes not working? Double-check format — needs to start with $6$ for SHA512
  • SSH failing? Make sure SSH is installed and the service is running
  • Hashcat not cracking? Try a different wordlist or make your own
  • Running same command twice? Add --potfile-disable to force it

📘 What I Learned

This challenge taught me a lot about password storage formats (like SHA512), how Linux stores passwords, and how tricky cracking can be when hashes aren’t aligned with your tools. I also learned that persistence pays off — you won’t always succeed on the first try, but there’s always a way forward if you’re patient and creative. 🔍💪

✅ Conclusion

Successfully cracking a password with Hashcat was a big win. From creating users and capturing hashes to building a custom wordlist and solving encryption format issues — it was a long but rewarding journey.
