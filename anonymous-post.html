Staying Anonymous online

Making yourself anonymous is a key part of ethical hacking. In this post, I’ll show you how I used Tor and Proxychains to hide my identity while browsing and testing. I’ll also share what worked, what didn’t, and what I learned along the way. 🧅🕵️

🛠️ What You’ll Need

  • Tor & Proxychains installed
  • Correct Commands
  • VPN config file
  • Some basic terminal skills

💡 Step-by-Step Commands

  1. Update & install Tor
    sudo apt update && sudo apt install tor -y
  2. Install Proxychains
    sudo apt install proxychains
  3. Start the Tor service
    sudo service tor start
  4. Configure Proxychains
    sudo nano /etc/proxychains.conf
    Find the existing socks4 line and replace/add:
    socks4 127.0.0.1 9050
  5. Test if it works
    proxychains curl https://check.torproject.org/
    proxychains firefox https://check.torproject.org/
  6. Use a VPN (optional but adds more privacy)
    sudo openvpn --config /path/to/your/vpn-config-file.ovpn
  7. Encrypt DNS with DNSCrypt
    sudo apt install dnscrypt-proxy
    sudo systemctl start dnscrypt-proxy
    sudo systemctl enable dnscrypt-proxy
  8. (Optional) Add another layer with I2P
    sudo apt install i2p
  9. 🎉 And that's it — you're officially anonymous online.

🐞 Troubleshooting

  • Tor not starting? Try:
    sudo systemctl restart tor
  • Firefox not launching? Make sure it's installed or try another browser.
  • VPN not working? Double-check the .ovpn file path.

📚 What I Learned

  • How anonymity works online and how many layers it actually takes to stay hidden.
  • The importance of configuring tools right, like editing the Proxychains config or choosing the correct socks version.
  • That privacy tools need to be combined — Tor alone isn’t enough, but with VPN, DNS encryption, and I2P, it’s much stronger.
  • Troubleshooting is part of the process — nothing worked immediately, but figuring it out helped me understand Linux and network settings better.
  • Being anonymous isn’t just one click — it's a full setup, and now I know how to do it.

🔚 Conclusion

By setting up Tor, Proxychains, a VPN, and encrypting my DNS, I successfully created a more anonymous browsing environment. The process taught me how various privacy tools work together to keep my identity hidden online. While there were a few hiccups along the way, like troubleshooting configurations and commands, it was rewarding to see it all come together in the end. Remember, maintaining online anonymity is an ongoing process, and these tools are just a start in ensuring your privacy. Stay safe and always keep learning! 🛡️💻
