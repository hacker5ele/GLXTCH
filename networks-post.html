Scanning Networks with Nmap

Network scanning is a crucial skill in cybersecurity. In this post, I'll walk you through how I scanned a network using Nmap to gather information about open ports and services. I'll explain the steps, what tools I used, and share what I learned along the way. 🌐🔍

🛠️ What You’ll Need

  • A Linux-based system (any Debian-based distro like Ubuntu, Kali, etc.)
  • Internet connection and access to the target system's IP
  • Basic terminal knowledge
  • Nmap installed (use sudo apt install nmap to install it, in case not preinstalled)

💡 Installation Steps

  1. First, make sure you have Nmap installed. If not, run sudo apt update && sudo apt install nmap
  2. Scan a target IP address: nmap -Pn "IP_ADDRESS"
  3. For a detailed scan: nmap -A "IP_ADDRESS"

🐞 Troubleshooting

If you run into issues while scanning, here are some common troubleshooting tips:

  • If Nmap returns nothing, make sure the target is reachable and online. The -Pn flag disables host discovery.
  • For "permission denied" errors, use sudo
  • To scan only specific ports and speed things up: nmap -p 80,443 "IP_ADDRESS"

💡 What I've Learned

Scanning networks with Nmap taught me the basics of discovering open ports and services running on a remote system. I learned how to use flags like -Pn to bypass host discovery and how to gather additional information using -A for a more comprehensive scan. Although the scan didn't yield a lot of useful information in this case, it was an important step in understanding how network scanning works.

🔚 Conclusion

In conclusion, using Nmap is a fundamental skill for network reconnaissance. Even though the scan didn’t provide much valuable data in my case, the process gave me a deeper understanding of network scanning and the types of information you can gather about a target system. Keep practicing and experimenting with different Nmap options to expand your skills. 🧑‍💻🔒
